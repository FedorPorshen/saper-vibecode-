# Сапёр 🧨

Нативный сапёр для Android: **каждое поле гарантированно решается логикой, без угадывания** — перед выдачей поля солвер проверяет его от начала до конца.

## Установка

Скачай [`Saper-1.0.apk`](Saper-1.0.apk), открой на телефоне (Android 7.0+) и разреши установку из этого источника.

## Возможности

- **Честные поля** — генератор переставляет мины, пока поле не станет решаемым; правило подмножеств покрывает паттерны 1-2-1.
- **Подсказки за время**: 💡 лампа — подсвечивает безопасную клетку и объясняет, почему она безопасна; 🧹 лопата — безопасно вскрывает выбранную клетку. Каждая трата: +30 секунд к времени, рекорд при этом засчитывается.
- **Рекорды и статистика** по трём сложностям (9×9/10, 16×16/40, 30×16/99).
- **Прогрессия**: опыт за победы, 11 званий от Новобранца до Маршала сапёрных войск, 7 достижений, даты получения званий.
- Классическое управление: тап — открыть, долгое нажатие — флажок (задержка настраивается), тап по цифре — аккорд; зум щипком.

## Сборка

```bash
git clone https://github.com/FedorPorshen/saper-vibecode-.git
cd saper-vibecode-
./gradlew :app:assembleRelease
```

Стек: Kotlin, Jetpack Compose, Room. Тесты: `./gradlew :app:testDebugUnitTest`.
