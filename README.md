# Сапёр для Android

**[Скачать Сапёр 1.3 (.apk)](https://raw.githubusercontent.com/FedorPorshen/saper-vibecode-/main/Saper-1.3.apk)**

Поддерживается Android 7.0 и новее. Откройте скачанный APK на телефоне и, если Android попросит, разрешите установку приложений из источника, в котором вы открыли файл.

## Как устроена игра

Первое нажатие и соседние клетки безопасны. Перед началом партии встроенный решатель проверяет, что от первого хода можно открыть все безопасные клетки логическими выводами. Если решатель застревает, генератор меняет раскладку и проверяет её снова.

- Три сложности — 9 × 9 с 10 минами, 16 × 16 с 40 минами и 30 × 16 с 99 минами.
- Короткое нажатие открывает клетку, долгое ставит флажок. Нажатие на открытую цифру раскрывает соседей, когда рядом уже стоит нужное число флажков. Поле можно масштабировать щипком.
- Лампа показывает безопасную клетку и объясняет ход, а лопата безопасно открывает выбранную клетку. Каждая подсказка добавляет 30 секунд к результату.
- Рекорды, статистика, звания и достижения хранятся на устройстве.

## Сборка из исходников

Откройте проект в Android Studio с Android SDK API 37 и JDK 25 для Gradle. Приложение написано на Kotlin с Jetpack Compose и Room.

В Windows запустите в корне проекта:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleRelease
```

В macOS или Linux:

```bash
./gradlew :app:testDebugUnitTest :app:assembleRelease
```

APK появится в `app/build/outputs/apk/release/app-release.apk`. Локальная сборка подписывается debug-ключом Android на вашем компьютере.
